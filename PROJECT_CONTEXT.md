## 5. Что важно не сломать

1. **Typing-bubble не исчезает** — «Разбираю…» рождается **внутри** `.typing-indicator__shell`.
2. **Не снимать `hero-typing` при `hero-replied`** — иначе bubble станет невидимым.
3. **Текст «Разбираю…»** — fade через `.is-text-visible` **после** расширения shell (`SHELL_EXPAND_MS = 720`).
4. **Появление bubble'ов** — `is-revealed` → rAF → `is-visible`. Не скрывать целые секции через `display:none`.
5. **Не анимировать width/max-height текста** — только opacity.
6. **Composer** — не `<input>`, ссылка на Telegram на весь блок.
7. **Две основные страницы** — правки портфолио не трогают `cart.*` и наоборот.
8. **Кейсы с модификаторами** (`--uws`, `--lm-print`, `--gethotel`) — у каждого свой hero; не ломать общие `.case-card` стили.

## 6. Правила по стилю и архитектуре

- **Шаг за шагом** — один блок / одна правка за раз
- **Порядок:** вёрстка → адаптив → анимации
- **Сверяться с Figma** — указывать `node-id`
- **Минимальные правки** — не переписывать работающее
- **Без npm, bundler, фреймворков** без явной просьбы
- **Не добавлять файлы** без объяснения зачем
- Пользователь — **дизайнер**, объяснять простым языком
- Правила проекта: `.cursor/rules/project-workflow.mdc`

### Структура CSS

- Переменные в `:root`
- Hero: `/* ── Hero reveal sequence ── */`
- Chat-reveal: `.chat-reveal` / `.is-revealed` / `.is-visible`
- Кейсы-варианты: `.case-card--uws`, `.case-card--lm-print`, `.case-card--gethotel`
- Адаптив: `@media (max-width: 720px)` в конце `styles.css`

### Тайминги `hero-sequence.js`

```js
TYPING_START_DELAY_MS = 350
MIN_TYPING_MS = 2500
REST_AFTER_ACHIEVEMENTS_MS = 400
BUBBLE_GAP_MS = 460
SHELL_EXPAND_MS = 720
```
